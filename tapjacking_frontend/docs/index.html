Tapjacking Demonstration App

This proof-of-concept showcases overlay behavior for educational and security testing purposes.

Quick Start

  1. Build with ./gradlew :app:assembleDebug
  2. Install with ./gradlew :app:installDebug
  3. Open the app "Tapjacking Demo".
  4. Allow the overlay permission when prompted via the button.
  5. Tap "Show Overlay" to begin the demo.

Permission Notes

Overlay permission can be found under Special access / Draw over other apps on many devices.

Serve this page

Run python3 -m http.server 3000 in this folder and open http://localhost:3000.
